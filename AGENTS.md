# ClaimGuard agent notes

This repository is a seed. Build product code here; do not assume an existing claims pipeline.

## Setup

- Node 20 or newer.
- Install with `npm install`.
- Verify with `npm run check`, `npm test`, and `npm run build`.

## Constraints

- Do not commit secrets or real patient or claim data.
- Keep changes on a branch and open a pull request when the task is ready for review.
